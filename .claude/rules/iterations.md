# 迭代紀錄與交接筆記的格式

## `AI/Doc/Iterations/Iteration-NN.md`

```
# Iteration NN — 一句話標題（結論，不是題目）

**日期：** YYYY-MM-DD
**依據：** 使用者：「原話」
**規則：** 這一輪守了什麼（例：只在開發期搜尋、保留期未開）

## 一、做了什麼
## 二、結果（表格；數字附來源：#experiment_n、結果檔、資料表）
## 三、讀法（結論與沒成立的事一樣要寫）
## 變更檔案
修改：…  新增：…
```

- 標題寫結論（「美股資料接入實測無助益」），不寫題目（「美股資料」）。負面結果照寫。
- 每個數字要能在結果檔或資料表找到；審查者會查。
- 寫完在 `AI/Doc/README.md` 迭代表**最上面**加一列（新的在前）。

## `progress.md`

固定七段，標題固定（儀表板「工作進度」頁靠標題解析）：
`## 任務`、`## 產出`、`## 已完成`、`## 決策`、`## 未解`、`## 下一步`、`## 階段`。
檔頭 `**更新：** YYYY-MM-DD`。階段用 `- [x]` 完成、`- [~]` 進行中、`- [ ]` 未開始。
決策要附日期與理由；下一步只寫**一個**可以直接動手的步驟。
