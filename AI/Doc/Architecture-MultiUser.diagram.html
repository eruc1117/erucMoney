多使用者與前後端分離架構

兩個改動：持股／交易台帳按使用者隔離；前端獨立成靜態網站放 GitHub Pages（免費）， 透過 RESTful API 連回家裡的後端。後端不搬家——PostgreSQL、排程器、模型全部留在本機，只把 Node.js 的 3001 埠 用免費隧道對外開一個 HTTPS 入口。綠色是要新增的部分。

使用者端 公開靜態 隧道／邊緣 本機服務 資料庫 新增
為什麼一定要隧道。GitHub Pages 是 HTTPS，瀏覽器不准 HTTPS 頁面呼叫 http://家裡IP:3001（mixed content）。 Cloudflare Tunnel 免費提供 HTTPS 憑證、不需固定 IP、不用在路由器開埠；家裡的 PC 只做出站連線。 沒有自己網域時用 cloudflared tunnel --url localhost:3001 的快速隧道（網址隨機、每次重啟會變）或 ngrok 免費靜態網域。

資料現況目標改法

user_trades全站一份；回放推導持倉每人一份加 user_id；回放（ledger_audit、/holdings/review）按人跑
/cash 閒置資金配置吃全站持股按登入者Node 把 user_id 的持股傳給 FastAPI /cash（FastAPI 不碰 users 表）
user_news 手動貼新聞混在爬蟲新聞裡記錄是誰貼的加可為空的 user_id；模型仍全部使用
查詢紀錄、主題、字級localStorage不變跟著瀏覽器走即可
行情、新聞、模型、預測、投票、週預測共用共用，需登入只加 auth 中介層
爬蟲觸發、模型凍結／服役、資料回補任何人可按admin 才能requireRole('admin')

順序

階段做什麼做完的樣子
1users 表 + auth + 持股／交易加 user_id（本機先跑）localhost 上兩個帳號看到不同持股；舊資料歸 admin
2前端登入頁、API 位址設定、Bearer、HashRouter、base 路徑本機 vite preview 用 /money/ 路徑能跑
3GitHub Actions 部署 Pagesgithub.io 打得開，API 指 localhost 時在自己電腦上可用
4cloudflared 隧道 + cors 白名單 + rate-limit手機在外面登入看得到自己的持股
5admin 端點加角色、Cloudflare Access（選配）外人拿不到爬蟲與模型管理
安全底線。後端一旦對外，所有端點都要驗 token（包括現在沒有驗的 /stocks）；密碼用 bcrypt；JWT 密鑰放環境變數不進 git； 只開 3001，FastAPI 與 LSTM 不進隧道；帳號由 admin 建，不開自助註冊。這些都在階段 1、4 內，不是之後再補。
