# Iteration 16 — 開盤跳空預測：把「已被吸收的資訊」變成有用的東西

**日期：** 2026-08-06

## 起點

Iteration 15 量測到一個看似矛盾的結果：

| 美股隔夜 → | 相關係數 |
|-----------|---------|
| 台股**開盤跳空** | **+0.66** |
| 台股盤中報酬 | −0.13 |
| 台股全日報酬 | +0.35 |

美股資訊在台股開盤瞬間被完全吸收——這解釋了它為何對「收盤到收盤」預測無用，
但同時也代表**開盤跳空本身是高度可預測的**。本迭代把這件事做成可用的功能。

## 一、模型（`UnifiedModel/train_gap.py`）

**預測目標：** 次一交易日的 `開盤價 ÷ 前日收盤 − 1`

**特徵：** 美股隔夜 17 個 + 個股 5 個。個股特徵的作用是提供「規模」資訊——
同樣的美股衝擊，高波動個股的跳空幅度較大：

| 個股特徵 | 用意 |
|---------|------|
| `own_vol_20d` | 近期波動度 |
| `own_gap_std20` | 該股歷史跳空幅度（只用過去資料，`shift(1)` 後才滾動） |
| `own_gap_ma5` | 近期跳空傾向 |
| `own_beta_proxy` | 個股波動 ÷ 全體平均波動，衡量對市場衝擊的放大倍數 |
| `own_ret_1d` | 前一日漲跌 |

**必須勝過的基準**（否則模型沒有存在價值）：

| 方法 | 相關係數 | R² | MAE | 方向準確率 |
|------|---------|-----|-----|-----------|
| 零跳空（永遠預測 0） | 0.0000 | −0.0282 | 0.8624% | — |
| 費半單變量（SOXX 線性迴歸） | 0.4222 | +0.1762 | 0.7671% | 62.68% |
| 大盤平均（忽略個股差異） | 0.4225 | +0.1766 | 0.7664% | 62.69% |
| **模型** | **0.5767** | **+0.2924** | **0.6647%** | **67.29%** |

樣本 142,292 筆 / 24 檔（2001-08 ~ 2026-08），5 折擴張視窗走查。
模型相對最強基準：R² 提升 66%、MAE 降低 13%、方向準確率 +4.6pp。

「大盤平均」基準特別重要——它證明**個股層級的特徵確實有貢獻**，
模型不只是把大盤跳空平均套用到每檔。

## 二、關於 70% 這個目標

使用者原本要求 70% 準確率。Iteration 12 證實「收盤到收盤」的方向預測做不到
（最佳 59.89% 且信賴下界貼著 50%）。

**跳空方向準確率 67.29% 是目前最接近的結果**，而且它是誠實的：
不是靠類別不平衡撐出來的（跳空方向約各半），也不是靠低出手率換來的
（全樣本 142,292 筆一起算）。

差別在於**問題本身可不可解**：漲跌方向受未來資訊驅動，本質不可預測；
跳空反映的是已經發生、只是還沒被台股價格反映的資訊。

## 三、定位必須說清楚：參考資訊，不是買賣訊號

跳空發生在開盤那一刻，事後無法交易。這個功能的用途是：

1. **盤前心理準備**——今晚美股這樣走，明天大概開在哪
2. **供風險模組使用**——預期大幅跳空時，停損距離必須把它算進去
3. **搭配投票結果解讀**——若某檔是 Buy 但預期大幅開高，
   代表進場成本已墊高，可考慮等回檔

程式碼、API 回應、前端標籤三處都明確標示「參考資訊，非買賣訊號」，
避免日後被誤用成交易訊號。

## 四、整合

| 層 | 變更 |
|----|------|
| 推論 | `Crawler/gap_model.py`——載入模型、以**最新一筆美股收盤**替換特徵後預測 |
| API | `GET /gap/predict[?stock_ids=2330,2303]`（FastAPI :8000） |
| 代理 | `Server/routes/gap.js` → Node :3001 |
| 前端 | `VotingDashboard.jsx` 新增 `GapPanel`，預設顯示漲跌各三名，可展開全部 |

推論時的關鍵細節：資料集中每一列的美股特徵對應的是「該台股日開盤前」的隔夜走勢，
但要預測**明日**跳空，必須把特徵換成**目前最新的美股收盤**。
`_build_latest_features()` 明確處理這件事，否則會用到過期一天的美股資料。

線上實測（台股最新 2026-08-06，採用 2026-08-05 美股收盤）：

```
2313 +1.17% 開高   220.50 → 223.08
2337 +0.99% 開高   129.00 → 130.28
...
2330 -0.45% 開低  2365.00 → 2354.26
5483 -1.36% 開低   177.50 → 175.09
```

24 檔平均 −0.17%，區間 −1.36% ~ +1.17%。

## 誠實評估與限制

1. **R² 0.29 代表仍有 71% 的變異無法解釋**。MAE 0.66% 意味著單檔預測
   平均誤差約 0.66 個百分點——方向多半對，幅度只能當粗估。
2. **未考慮台股自身的隔夜消息**（法說會、重大訊息、除權息）。
   除權息日的「跳空」是配息造成的機械性缺口，模型會誤判為真實跳空。
   目前資料沒有除權息旗標，這是已知的誤差來源。
3. **模型在美股休市時會沿用最後一個交易日**（`us_gap_days` 有記錄天數）。
   連假後的預測可靠度較低。
4. **未回測「等回檔再進場」這類應用**。本迭代只驗證跳空預測本身的精度，
   沒有驗證任何基於它的交易規則。
