## 一、預測比對頁「連展開都無法」（`d44308a`）

症狀不是按鈕壞掉，是整張卡片的內容被 IntersectionObserver 擋住：資料抓取與繪圖
都設在「卡片接近視窗才做」，觀察沒送出回呼，卡片就永遠停在「載入比對資料…」。
舊版掛載後只產出 18KB DOM，新版 174KB。

三個修正：拿掉 IntersectionObserver 改用分頁（每頁 6 筆）；每張圖與明細包進
ErrorBoundary（React 預設 render 拋例外就卸載整棵樹）；混合圖 `chart.type` 改回 `'line'`。

## 二、三層自動檢查

這一輪建立了之後每次前端改動都會跑的三支檢查：

| 檢查 | 指令 | 抓什麼 | 抓不到什麼 |
|------|------|-------|-----------|
| `smoke.mjs` | `npm run smoke` | jsdom 掛載每頁，抓 render 例外 | 版面 |
| `smoke-interact.mjs` | `npm run smoke:ui` | 真的按按鈕，抓「掛起來了、按下去沒東西」 | 版面 |
| `ui-check.mjs` | `npm run ui` | Playwright 真瀏覽器量版面：壓扁、裁切、橫向溢出、零高度 | — |

第三支裝好第一次跑就抓到兩個問題：圖例只有色點沒文字（`parseInt('0.8125rem')` 是 0，
新增 `chartPx()`）；信賴區間根本沒畫出來（改用 rangeArea）。

## 三、整頁被壓扁看不見（`c9d8213`）

真正原因是 Iteration 25 在 `.card` 加了 `overflow: hidden`：flex 子項的自動最小尺寸
只在 overflow 為 visible 時等於內容高度，一旦 hidden 就變 0，內容總高超過視窗時
所有卡片被壓縮、內容被裁掉。修正 `.content > * { flex-shrink: 0 }`。
這個 bug 的特徵值得記著：**DOM 完整、無錯誤訊息、畫面卻是空的**，jsdom 驗不出來。

## 四、閒置資金一週配置（`32ecdf4`，新頁 💵）

需求寫的是「最大化利益」，但那需要知道哪支會漲多少，而 Iteration 11/12/22 已反覆
證明方向不可預測。所以這裡最大化的是**風險調整後的期望價差空間**：
振幅模型決定值不值得動用資金、波動率模型決定停損與部位、籌碼機率只做 0.85~1.15 微調。

三個實作判斷：風險預算先切分再配置（不能第一檔吃光 2%）；檔數切太細自動往下縮；
來回成本佔期望價差超過 40% 一律拒絕並顯示原因。

順帶修掉三個模組「先載入全部歷史再檢查快取」的效能 bug：新增 `panel_cache`
用 `max(trade_date)` 當快取鍵，配置 23.4 秒 → 首次 9.2 秒、之後 1.5 秒。
