# Iteration 59 — 程式交易回放：引擎規則套在過去六年，停損 15%／25%／35% 都輸給「照單全收」，限價 ±0.5% 也少賺 1.9%／年

**日期：** 2026-10-09
**依據：** 使用者：「都是假裝有接，並且可以依照過去資料模擬接之後的獲利或是賠」——券商先假接（紙上），但要能用歷史資料回放「接上引擎之後」會賺還是賠。
**規則：** 回放和引擎用**同一份**規則程式（新的 `trading_rules.py`，純函式）；清單用候選回測存下的 `portfolio_positions`（run 44，2018-11-12 ～ 2024-09-11），
所以只能回放候選期間——保留期（2024-10 起）沒有清單，也不在這裡開（超出會夾回並在回應裡說明）。本輪不改候選、不開引擎。

## 一、做了什麼

### 規則抽成純函式：`Crawler/trading_rules.py`

`rebalance_orders`（清單 → 先賣後買的委託，買單按現金＋賣出淨額縮，`guard` 時不產生買單，`slip=None` = 市價）、`stop_loss_orders`（收盤 ≤ 成本 × (1 − pct)；pct = 0 代表關閉）、
`fill_orders`（隔天行情模擬零股限價：買開盤 ≤ 限價、賣 ≥；鎖死、沒行情未成交；沒持股拒絕、有持股縮到持股數；現金不夠縮單）、`requote`（到上限取消，否則新收盤重掛）。
`trading_engine.py` 改呼叫 `rebalance_orders`／`stop_loss_orders`／`limit_price`／`requote`（重掛與取消也走同一份），`brokers/paper.py` 改呼叫 `fill_orders`；行為不變，原本引擎 5 項與紙上帳戶 5 項測試照過。

### 回放：`Crawler/trading_replay.py`

`replay(start, end, capital, rules, run_id)`：載清單、載範圍內所有相關股票的日線（一次查詢；**還原價**——開高低收乘上 adj_close ÷ close，持股含息，和對手 0050 的 adj_close 對稱，回測也是用還原價；前收用各檔自己的上一筆）；
逐日跑兩個版本——**engine**（限價、重掛、停損、相對回撤守門）與 **plain**（市價、次日開盤照單全收、鎖死就算了，= 紙上交易原本的方式）；
算總報酬、0050、年化主動報酬、追蹤誤差、IR、月勝率、相對最大落後、換手、成本、逐年主動報酬、委託／成交／重掛／取消／停損次數、停損的已實現損益；
回 400 點以內的淨值序列與 `engine_minus_plain`。結果快取 16 組。候選期間（六年、68 份清單、306 檔）一次約 3.2 秒（還原價版；第一版 2.4 秒）。

### API 與頁面

`GET /trading/engine/replay?start&end&capital&run_id&stop_loss_pct&rel_dd_guard&limit_slip&max_attempts`（FastAPI 驗參數；Node 代理只轉這八個鍵）。
頁面「程式交易」多一個分頁**歷史模擬**：期間、資金、四個規則參數與四個快捷鍵（停損 15%／25%／不停損／限價 ±1%）→ 五格摘要、三條淨值線（引擎、照單全收、0050）、指標對照表（含引擎 − 照單）、逐年主動報酬、停損紀錄、caveat。

## 三、讀法

1. **停損對這個策略是壞事**，而且不是參數問題：15%／25%／35% 都輸給不停損（+228%／+256%／+277% 對 +304%），差別只是輸多少。月動能策略本來就靠「跌下去的抱到下個月換掉」賺反彈，停損把反彈砍掉又多付稅。回測沒有停損（候選的 +7.05% 是無停損的數字），這和回測一致。
2. **限價 ±0.5% 也有代價**：六年 975 次重掛、170 張取消，年化主動 +6.03% 對照單全收 +7.89%，少賺約 1.9%／年——沒成交的多半是開高的那些，正是動能股。±2% 只差 0.5%／年。零股限價要掛就掛寬一點，或改市價（盤後零股是集合競價，本來就接近「照單全收」）。
3. 所以**接上凱基之前，引擎的預設規則應該改**：停損關掉（0）、限價放寬到 ±2% 或市價。這一輪沒改預設（`RULES_DEFAULT` 仍 15%／0.5%）——改不改由使用者在頁面「引擎」分頁或回放結果上決定。
4. 回放不是回測：它沒有盤中路徑、沒有流動性衝擊、沒有滑價、清單是候選回測算好的（含當時的台積電權重估計）。它回答的是「同一份清單換一種執行方式會差多少」，不回答「策略有沒有效」（那是 DSR 的事）。
5. 沒做的：保留期回放（沒清單、不該開）、盤後零股集合競價的成交模型、把回放結果存進 `portfolio_runs`（它不是新實驗，不算 N）。
6. 這份紀錄交 evidence-reviewer 審過一輪：56 條主張 40 verified、4 incorrect（持股不含息的不對稱、引擎重掛沒走共用函式、測試項數、URL 少 run_id——都已改，前兩項改的是程式）、12 unresolved（當時只有預設規則那組在 checks.json，現在七組加 replay-meta 都在）。
